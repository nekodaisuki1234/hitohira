# ひとひら

スマホ向け「次の行動を決めるカード」。ログイン・外部AI・サーバー保存不要の静的Webアプリです。

## 起動と検証

Node.js 18以降で `npm test`。Python 3で `npm start` を実行し、http://localhost:8080 を開いてください。ビルドや依存関係のインストールは不要です。

## 使い方

「カードを引く」で1枚を選び、「できた！」か「今は無理」で次へ進みます。設定から在宅／外出、元気／疲れ気味、生活日の区切り、行動名・所要時間・最初の一歩・出現条件を変更できます。

生活日は午前4時が初期値。生活習慣の完了は各カードの対象時間帯の開始日に紐づくため、夜の歯磨きは午前0時になっても再登場しません。条件を絞った重み付き抽選で習慣を優先し、休憩などが2枚続いた場合は次の抽選を対象の習慣に限定します。スキップしたカードは次の1回から除外し、候補がなければ休止表示にします。疲れ気味なら短時間のカードの重みを増やし、23〜4時は寝る準備だけを候補にします。

設定・実行中のカード・完了記録はlocalStorageへ保存。ブラウザデータ削除や別のブラウザへの切り替えでは引き継がれません。タイマーは絶対時刻から再計算し、自動完了しません。実行中のカードは設定変更の影響を受けません。時刻と日付は端末のローカル時間を使います。

`core.js` の `defaults` で初期カードを編集できます。ブラウザの設定画面から既存カードの調整もできます。画面は320px以上のスマホ幅に対応し、アニメーション軽減設定を尊重します。

GitHub Pagesはリポジトリの Settings → Pages → Deploy from a branch → main / (root) で公開できます。
